# 🤖 دستیار کدنویسی تلگرام

ربات دستیار کدنویسی با پنل ادمین - اجرا روی Cloudflare Workers

## قابلیت‌ها

- 💬 چت هوشمند با Claude AI
- 🐛 دیباگ کد با شماره خط
- 📷 تحلیل اسکرین‌شات خطا
- 🗜️ تحلیل پروژه ZIP
- 🐙 یکپارچه‌سازی GitHub (پوش، برنچ، PR)
- 🖥️ پنل ادمین وب
- 🧠 اتصال مدل هوش مصنوعی شخصی هر کاربر (پولی یا رایگان) با دکمه‌های شیشه‌ای

## منوی فرمان‌های تلگرام

فهرست فرمان‌ها پس از اولین پیام دریافتی از ربات، خودکار با Telegram Bot API ثبت می‌شود. این فهرست شامل `/start`، `/help`، `/ai`، `/login`، `/logout`، `/project`، `/github`، `/github_off`، `/workspace`، `/workspace_clear`، `/lang`، `/search`، `/debug`، `/clear` و `/new` است. زیرفرمان‌های اتصال و همگام‌سازی مخزن، مثل `repo`، `sync`، `pull` و `push`، از طریق `/project` اجرا می‌شوند.

ثبت فرمان‌ها فقط منوی slash-command تلگرام را به‌روز می‌کند؛ دکمه‌های فعلی ربات در جای خود باقی می‌مانند. برای تحلیل عکس، فایل کد یا ZIP، فایل را مستقیم به گفتگو پیوست کنید.

## اتصال مدل شخصی (Bring Your Own Key)

کاربرانی که به مدل پولی دسترسی ندارند می‌توانند مدل خودشان را وصل کنند:

1. دستور `/ai` یا میان‌بر `/login` را بفرستند (یا دکمه «🔌 اتصال مدل شخصی» را بزنند)
2. **Base URL** سرویس را بفرستند — باید به `/v1` ختم شود (مثلاً `https://api.openai.com/v1`)
3. **API Key** را بفرستند — پیام حاوی کلید بلافاصله از چت پاک می‌شود
4. **نام مدل** را بفرستند — ربات اتصال را تست می‌کند و در صورت موفقیت وصل می‌شود

- دکمه‌های اتصال، وضعیت، تغییر مدل و راهنما به‌صورت منوی شیشه‌ای مرتب زیر پیام نمایش داده می‌شوند؛ دکمه‌های قدیمی کیبورد متنی نیز برای سازگاری پذیرفته می‌شوند.
- هر سرویس سازگار با OpenAI API پشتیبانی می‌شود (OpenAI، Groq، OpenRouter و...)
- مشخصات هر کاربر جداگانه در KV ذخیره می‌شود (`ai_conn:<userId>`)
- پس از اتصال، همه قابلیت‌ها (چت، دیباگ، عکس، فایل، ZIP، ایجنت گیت‌هاب) با مدل خود کاربر کار می‌کنند
- حذف اتصال: `/logout`، `/ai off` یا دکمه «🗑 حذف اتصال»
- تست محلی: `node test.mjs`

## فضای کار و حافظهٔ جداگانه برای پروژه‌ها

قابلیت پروژه‌ای به‌صورت افزایشی اضافه شده است. تا وقتی پروژه‌ای را فعال نکنید، ربات از همان حافظه و فضای کاری پیش‌فرض قبلی استفاده می‌کند. برای ساخت و مدیریت پروژه‌ها:

```text
/project                     راهنمای فرمان‌ها و پروژهٔ فعال
/project new <نام>           ساخت پروژه و فعال‌کردن آن
/project list                فهرست پروژه‌ها
/project use <نام>           جابه‌جایی به یک پروژه
/project off                 بازگشت به حافظه و فضای کار پیش‌فرض
/project delete <نام>        حذف پروژه، حافظه و فایل‌های workspace آن
/project repo <owner/repo>   اتصال مخزن GitHub به پروژهٔ فعال
/project sync                منوی دریافت/ارسال GitHub
/project pull [overwrite]    دریافت فایل‌ها از GitHub
/project push                پیش‌نمایش و ارسال پس از تأیید
```

منوی `/project` امکان انتخاب پروژه و اتصال GitHub را از طریق دکمه‌های شیشه‌ای هم می‌دهد. ابتدا با `/github <توکن>` توکن را وصل کنید، سپس پروژه را فعال و مخزن را با `/project repo owner/repo [branch]` ثبت کنید. `pull` فایل‌های جدید را بدون overwrite وارد workspace می‌کند؛ فایل‌های هم‌نام حفظ می‌شوند. برای جایگزینی صریح از `/project pull overwrite` استفاده کنید. `push` ابتدا مقصد و فهرست فایل‌ها را پیش‌نمایش می‌دهد و فقط با فشردن دکمهٔ تأیید، فایل‌های workspace را به‌صورت commit اضافه/به‌روزرسانی می‌کند؛ فایل‌های دیگر مخزن حذف نمی‌شوند. فایل‌های `.env` و مسیرهای حساس/ساخت خروجی از sync کنار گذاشته می‌شوند و دریافت محدودیت اندازه و تعداد دارد. هر پروژه حافظه و workspace خودش را دارد؛ داده‌های قدیمی پیش‌فرض حفظ می‌شوند و با `/project off` در دسترس‌اند.

## تنظیمات لازم

### Secrets (از طریق Cloudflare Dashboard یا Wrangler CLI)

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put OPENAI_API_KEY        # اختیاری
npx wrangler secret put ADMIN_SECRET           # اختیاری - برای پنل ادمین
npx wrangler secret put WEBHOOK_SECRET         # اختیاری
```

⚠️ `TELEGRAM_BOT_TOKEN` را در تنظیمات Worker با نوع **Secret** ذخیره کنید، نه به‌صورت متغیر plain text. برای GitHub Actions، فقط `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID` را در Secrets مخزن قرار دهید؛ توکن تلگرام در Secret خود Worker باقی می‌ماند. Wrangler با deploy معمولی Secretهای موجود را حذف نمی‌کند.

### Bindings

- **D1 Database**: برای حافظه گفتگو و کاربران
- **KV Namespaces**: 
  - `STATS`: آمار، تنظیمات، توکن گیت‌هاب، فضای کار
  - `FILES`: متادیتای فایل‌ها
